# Creative Showcase

A responsive web application for artists to upload and showcase their digital artwork.

## Features
- User authentication (signup/login)
- Image upload with title and description
- Public profile pages
- Masonry layout gallery
- Responsive design

## Technologies
- React
- Tailwind CSS
- localStorage (demo - replace with backend)

## Setup
1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm start`
4. Open http://localhost:3000

## Deployment
Deploy to Vercel  by connecting  GitHub repository.
